# 06. Talent Pool (인재풀 등록)

신규 기능, 태희님 요청 (2026-09-09). 라우트 `/recruit/talent-pool` 예정.

## 진입 지점

1. `/recruit` 목록 페이지 하단 **상시 배너** — 공고 유무와 무관하게 항상 노출 ("찾는 공고가 없다면 인재풀에 등록해보세요")
2. `/recruit/[slug]` 상세 페이지에서 **마감된 공고**일 때 "지원하기" 버튼 자리를 "인재풀 등록하기"로 교체
3. 별도 라우트 **`/recruit/talent-pool`**

## 레퍼런스 조사 (5건) — UI/필드 구성은 테레스 채택 확정

링크와 확인 내용은 `context/레퍼런스.md` 참고. 요약:

- 현대차·모두싸인은 접근 제약(403 등)으로 일부만 확인
- **SK머티리얼즈** — 계정 없는 1회성 폼, 전 필드 선택, 별도 동의 체크 없음(문구로만 안내)
- **YTN** — 계정 가입형(이름·생년월일·비밀번호), 마이페이지에서 지원 현황 확인 가능 — 렛서 규모엔 과함, 채택 안 함
- **테레스(theres.company/talentpool)** — 계정 없는 1회성 폼 + 명확한 동의 UX, **최종 채택**. 스크린샷으로 실제 화면도 확인 완료

## 폼 필드 (테레스 기준, 전화번호만 수정해서 채택)

1. **개인정보 수집·이용 동의** — 스크롤 가능한 안내 박스(수집 항목·처리 목적·보유기간 명시) + 하단 체크박스, **필수**. 문구는 렛서 법무·개인정보처리방침 기준으로 다시 작성 필요(테레스 문구 그대로 쓰면 안 됨)
2. **이름** — 필수, 텍스트
3. **이메일** — 필수, 텍스트
4. **전화번호** — 필수, **단일 입력 필드**(테레스는 3칸 분리 — 예스러운 UX라 지양하기로 결정)
5. **희망 포지션** — 선택, 자유 텍스트(드롭다운 아님)
6. **이력서** — 선택, 파일 업로드
7. **포트폴리오** — 선택, 파일 업로드
8. **경력/경험 자유 기재** — 선택, 텍스트에어리어. 안내 문구: "경력·경험이 담긴 추가 자료가 있으시다면 자유롭게 기재해주세요 (링크드인, 노션, SNS, Github 등)"
9. **제출 버튼** — 문구 "작성"(가안), 렛서 브랜드 컬러 적용(테레스는 오렌지 단색 — 렛서는 딥그린/민트 계열로 대체)

## 시각 스타일 참고 (테레스 스크린샷 실측 기준)

- 좁은 1컬럼 폼(전체 폭 아님, 약 780px 추정), 좌측 정렬
- 필수 표시는 텍스트 "필수" 대신 **라벨 옆 빨간 점**
- 인풋은 사각 보더, 라운드 거의 없음
- 파일 업로드는 드래그앤드롭 없이 **"파일 올리기" 버튼 하나**로 심플하게 처리
- 제출 성공 시 모달 팝업(테레스 기준) — 렛서도 동일 패턴 채택 검토

## 백엔드/구현 방향 (미착수)

- Next.js API 라우트 + 가벼운 DB(예: Vercel Postgres 등, 인프라 미확정)로 전혜림이 직접 구현 — 9/3 "DB/프론트는 전혜림" 결정 재확인(2026-09-09)
