## 인재풀 등록 (2026-09-09, 태희님 요청)

채용공고 페이지에 "인재풀 등록" 기능 추가 요청에 따른 레퍼런스 5건.

- <https://talent.hyundai.com/talent/talentSave.hc> — 현대자동차 (등록 완료 페이지만 확인, 폼 구조 미확인)
- <https://recruit.modusign.co.kr/ko/o/159305> — 모두싸인 (403, 미확인)
- <https://careers.sk-materials.com/user/submitPool> — SK머티리얼즈 (계정 없는 1회성 폼: 지원기업·직무·경력기간·이력서 첨부, 전부 선택 항목, 별도 동의 체크 없음)
- <https://recruit.ytn.co.kr/pool_01.php> — YTN (계정 가입형: 직무·이름·생년월일·비밀번호 + 개인정보 동의 체크박스)
- <https://www.theres.company/talentpool> — 테레스. WebFetch는 403이었으나 `curl`(브라우저 User-Agent)로 실제 HTML 확보 + 사용자 스크린샷으로 시각 확인까지 완료. **최종 채택안** — 계정 없는 1회성 폼: 개인정보 동의(스크롤박스+체크박스, 필수) → 이름/이메일/전화번호(필수) → 희망포지션/이력서/포트폴리오/경력링크 자유기재(전부 선택) → 제출. 폼 필드 상세는 `../stories/06-talent-pool.md` 참고.
